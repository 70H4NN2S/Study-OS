# EX-0011 — Range labeling

**Time:** ~15 min · **Skill:** `PROG-C-CONTROL`

**Task:** Read `n` (1..100); print lines 1..n as number, `Fizz` (multiple 3), `Buzz` (multiple 5), or `FizzBuzz` (both).

**Cases (stdin → stdout):** `"5\n"` → `"1\n2\nFizz\n4\nBuzz\n"` · `"3\n"` → `"1\n2\nFizz\n"`

**Rules:** One label per line, test combined case first.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0011`.
