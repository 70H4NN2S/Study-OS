# EX-0042 — Dynamic vector I

**Time:** ~25 min · **Skill:** `PROG-C-HEAP`

**Task:** Read n (0..20), allocate a dynamic array with `malloc`, read n integers, and print in reverse order.

**Cases (stdin → stdout):** `"3 1 2 3\n"` → `"3 2 1\n"` · `"1 7\n"` → `"7\n"`

**Rules:** No variable-length arrays; free allocation.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0042`.
