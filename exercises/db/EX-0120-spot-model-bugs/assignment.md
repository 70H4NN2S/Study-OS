# EX-0120 — Audit and repair a broken ER model

**Time:** ~25 min · **Skill:** `DB-ERM-VALIDATION`

**Task:** Requirements: each Learner may join 0–6 Courses; each Course has 0–40 Learners; a mark belongs to each enrollment; course titles may repeat. A bad diagram has (1,1) on both sides of 'joins', Course.title as the key, and mark attached to Learner. Identify all distinct errors and repair them.

**Checks:** Give counterexample instances for two failures.

**Submit:** corrected diagram + brief notes. Send a clear photo/export in chat, or commit it in this exercise's `submission/` folder and link the exact GitHub commit/PR. See [track rules](../README.md); no mandatory reflection.
