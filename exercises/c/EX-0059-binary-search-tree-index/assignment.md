# EX-0059 — Binary search tree index

**Time:** ~50 min · **Skill:** `PROG-C-ALGORITHMS`

**Task:** Read n (0..6) distinct ints; insert into a heap-backed binary search tree; print in-order values.

**Cases (stdin → stdout):** `"3 5 2 8\n"` → `"2 5 8\n"` · `"1 7\n"` → `"7\n"`

**Rules:** No balancing/deletion. Free all allocated nodes.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0059`.
