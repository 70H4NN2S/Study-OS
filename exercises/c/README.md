# C — 100 short coding exercises

**5–55 minutes each.** One small C problem at a time. Learn syntax, features and conventions—not 100 full projects.

1. Open an exercise from the table.
2. Write `src/main.c` (and only extra files explicitly requested).
3. Run `python3 tools/check_c.py EX-0001` with your ID, then commit your code.
4. Send the commit/PR for review. No mandatory `tests.md` or `reflection.md`.
