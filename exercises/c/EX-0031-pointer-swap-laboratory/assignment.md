# EX-0031 — Pointer swap laboratory

**Time:** ~15 min · **Skill:** `PROG-C-POINTERS`

**Task:** Implement `void swap(int *a,int *b)`; read two integers and print them swapped.

**Cases (stdin → stdout):** `"5 -2\n"` → `"-2 5\n"` · `"0 9\n"` → `"9 0\n"`

**Rules:** Use pointers to change the caller's variables.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0031`.
