# Instructions to ChatGPT and coding agents

Start with [STUDY_OS.md](STUDY_OS.md), then [state/NOW.md](state/NOW.md), [state/DECISIONS.md](state/DECISIONS.md), goals and relevant curriculum/task files. A Study OS learning request naming a topic or supplying study material **defaults to creating an exercise/project/exam PR without a second confirmation**; read the supplied and relevant existing material first. A grading request instead triggers submission review and a proposed state-update PR. Explicit discussion-only requests must not create assignments. This is a human-triggered study platform, not autonomous background software. Use PRs for exercise creation and substantial state changes; do not merge without authorization. Grade only linked evidence. Respect help limits and repository publicity. For new artifacts follow templates, register stable skill IDs, and run `python3 tools/validate.py` when possible.
Use short 5–60 minute exercises and minimal case-driven descriptions by default; read the shared authoring rules in STUDY_OS.md. Never require routine reflection/test reports for microchallenges.
