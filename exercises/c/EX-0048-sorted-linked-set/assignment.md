# EX-0048 — Sorted linked-set

**Time:** ~50 min · **Skill:** `PROG-C-LISTS`

**Task:** Read n (0..8) signed integers, insert into a heap-backed singly linked list in ascending order without duplicates, and print it.

**Cases (stdin → stdout):** `"5 3 1 3 -2 2\n"` → `"-2 1 2 3\n"` · `"0\n"` → `"\n"`

**Rules:** Implement head insertion, middle insertion and cleanup. This is not the university FIFO assignment.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0048`.
