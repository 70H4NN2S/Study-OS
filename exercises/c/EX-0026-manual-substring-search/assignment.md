# EX-0026 — Manual substring search

**Time:** ~25 min · **Skill:** `PROG-C-STRINGS`

**Task:** Read two whitespace-free tokens (haystack, needle); print first zero-based substring index, or `-1`.

**Cases (stdin → stdout):** `"banana ana\n"` → `"1\n"` · `"hello xyz\n"` → `"-1\n"`

**Rules:** Implement scanning yourself, without `strstr`.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0026`.
