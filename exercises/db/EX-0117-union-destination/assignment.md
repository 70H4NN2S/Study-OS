# EX-0117 — Model an EER union/category type

**Time:** ~23 min · **Skill:** `DB-EER-CATEGORY`

**Task:** Every Parcel(parcel_id) goes to one Destination that is either a Store(store_id) or a Home(home_id). Store and Home have unrelated identifying schemes and no natural shared superclass; each may receive any number of parcels. Model Destination as an EER category/union.

**Checks:** Show category membership without inventing a global common identifier.
