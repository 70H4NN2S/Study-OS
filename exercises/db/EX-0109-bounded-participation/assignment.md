# EX-0109 — Model exact upper and lower bounds

**Time:** ~15 min · **Skill:** `DB-ERM-CARDINALITY`

**Task:** A StorageRack (rack_id) contains 1–4 Pallets. A Pallet (pallet_id globally unique) belongs to exactly one rack. Model the relationship with min–max participation.

**Checks:** Test the invalid cases: empty rack, five pallets, pallet shared by two racks.

**Submit:** diagram/photo/PDF. Send a clear photo/export in chat, or commit it in this exercise's `submission/` folder and link the exact GitHub commit/PR. See [track rules](../README.md); no mandatory reflection.
