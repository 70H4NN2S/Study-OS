# EX-0032 — Reverse a span

**Time:** ~20 min · **Skill:** `PROG-C-POINTERS`

**Task:** Read n (0..20) and n integers; reverse them in place using two pointers.

**Cases (stdin → stdout):** `"4 1 2 3 4\n"` → `"4 3 2 1\n"` · `"1 7\n"` → `"7\n"`

**Rules:** Print space-separated numbers, no trailing space.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0032`.
