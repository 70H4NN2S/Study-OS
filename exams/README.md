# Exams

User requests 1–2 weekend exams. Exam A: recent + weak + overdue topics. Exam B (optional): cumulative mixed-topic transfer. Store in `exams/YYYY/YYYY-Www-title/` with exam.md, submitted evidence and evaluation.md. Follow templates/exam.md and templates/evaluation.md. Specify time, rules, point allocation and delivery. Do not include solution keys before submission. Retakes append attempts, never overwrite history.
