# EX-0004 — Signed number inspector

**Time:** ~8 min · **Skill:** `PROG-C-CONTROL`

**Task:** Read one signed integer; print its sign and parity.

**Cases (stdin → stdout):** `"-3\n"` → `"negative odd\n"` · `"0\n"` → `"zero even\n"`

**Rules:** Use `negative`, `zero`, or `positive` followed by `even` or `odd`.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0004`.
