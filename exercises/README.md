# Exercises

One folder per exercise: `exercises/<domain>/EX-NNNN-slug/assignment.md`. The ID is global, unique and recorded in state/assignments.csv. Optional starter files, unit tests, submission/ files and reflection.md live beside assignment.md. Markdown is canonical; attach PDF when useful/requested. Exact deliverables, submission instructions, allowed assistance, rubrics, and verification must be explicit. Nothing is assigned yet. See templates/exercise.md.

## C mastery practice
See [100 original C exercises](c/README.md), the [curriculum map](../curriculum/c-mastery-roadmap.md), and `tools/check_c.py` for published deterministic cases. Tasks are registered as `proposed` until review/merge; no learning progress is asserted by their creation.

## ER/EER database modeling
[24 small, original Chen modeling exercises](db/README.md) start from identifying entities and finish with EER, view integration, relational mapping and a capstone. Submit clear diagram images/photos or text in chat, or commit the artifact for review. The evaluator checks semantic accuracy manually; no course homework answers are included.

## Symmetric cryptography
[10 short exercises](security/README.md) aligned with sec-02-crypto.pdf, including classical cryptanalysis and modern AES modes. Public vectors: `python3 tools/check_crypto.py EX-0125`.
