# C practice roadmap

**Goal:** become fluent in C11 syntax, pointers, types, library functions, memory safety, conventional builds and selected POSIX interfaces through **short code drills**. The 100 exercises are a menu for deliberate practice, not a compulsory 100-project workload.

| IDs | Focus |
|---|---|
| 01–10 | Core syntax and safe arithmetic |
| 11–20 | Loops, arrays and algorithms |
| 21–30 | Strings and parsing |
| 31–40 | Pointers, structs and callbacks |
| 41–50 | Heap memory and small containers |
| 51–60 | Modules, Make and preprocessor |
| 61–70 | C streams and temporary files |
| 71–80 | POSIX calls and process control |
| 81–90 | Synchronization and loopback sockets |
| 91–100 | C memory and focused integration |

Use [the compact C index](../exercises/c/README.md). Most drills require one C source file, two public examples and 5–55 minutes. All cases are concrete; a reviewer separately checks boundary cases and independent understanding. Retention is tracked only after real submission, not merely after reading or compiling. Interleave old topics in later exercises. Bigger portfolios/projects and exams are optional separate work.

**Calibration:** Original scenarios draw on concepts covered in the user's TU Braunschweig operating-systems lectures (C, pointers, memory management, compilation and POSIX) plus independently selected advanced C features. They do not reproduce course assignments or permit AI on graded university homework.
