# EX-0017 — Insertion sort trace

**Time:** ~30 min · **Skill:** `PROG-C-ALGORITHMS`

**Task:** Read `n` (0..20), followed by n integers; insertion-sort ascending, printing the array after each outer iteration.

**Cases (stdin → stdout):** `"3 3 1 2\n"` → `"1 3 2\n1 2 3\n"` · `"2 2 1\n"` → `"1 2\n"`

**Rules:** Print nothing for n<2; each row space-separated.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0017`.
