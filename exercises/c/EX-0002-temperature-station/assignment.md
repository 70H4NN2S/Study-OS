# EX-0002 — Temperature station

**Time:** ~10 min · **Skill:** `PROG-C-TYPES`

**Task:** Read integer Celsius `c`; print Fahrenheit with one decimal.

**Cases (stdin → stdout):** `"25\n"` → `"77.0\n"` · `"-40\n"` → `"-40.0\n"`

**Rules:** Use `9.0*c/5+32` or equivalent; avoid integer truncation.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0002`.
