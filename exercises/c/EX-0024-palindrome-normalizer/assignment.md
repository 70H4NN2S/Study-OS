# EX-0024 — Palindrome normalizer

**Time:** ~25 min · **Skill:** `PROG-C-STRINGS`

**Task:** Read an ASCII line; print `yes` if it reads identically backward ignoring case and punctuation, otherwise `no`.

**Cases (stdin → stdout):** `"A man, a plan, a canal: Panama\n"` → `"yes\n"` · `"hello\n"` → `"no\n"`

**Rules:** Do not allocate a second full-size string.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0024`.
