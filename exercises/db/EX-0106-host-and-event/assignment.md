# EX-0106 — Model the first binary relationship

**Time:** ~15 min · **Skill:** `DB-ERM-CARDINALITY`

**Task:** Every Meetup (meetup_id) has exactly one Host (host_id). A Host can organize zero or many Meetups. Draw two Chen entities and a named relationship with min–max participation at both ends.

**Checks:** Could a new Host exist without Meetups? Could a Meetup exist without a Host?
