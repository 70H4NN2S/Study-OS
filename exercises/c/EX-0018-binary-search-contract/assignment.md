# EX-0018 — Binary search contract

**Time:** ~25 min · **Skill:** `PROG-C-ALGORITHMS`

**Task:** Read `n` (0..20), a sorted array, then a target; print first matching index or `-1`.

**Cases (stdin → stdout):** `"4 1 2 2 4 2\n"` → `"1\n"` · `"3 1 2 3 9\n"` → `"-1\n"`

**Rules:** Use binary search, not a linear scan.

**Submit:** `src/main.c`. Check: `python3 tools/check_c.py EX-0018`.
